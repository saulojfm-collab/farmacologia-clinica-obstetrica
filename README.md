# Farmacologia Clínica Obstétrica

Aula interativa para a pós-graduação em Obstetrícia e Neonatologia. Professor: Dr. Saulo Mendes.

Site: https://saulojfm-collab.github.io/farmacologia-clinica-obstetrica/

Para uso offline, baixe o repositório, extraia e abra index.html, mantendo a pasta assets junto dos arquivos. Internet é necessária apenas para fontes externas e links de referências.

Conteúdo: plano dos três turnos, fundamentos PK/PD, corpo clicável, simulador conceitual, medicamentos, seis casos snowball e avaliação por competências.

As respostas e fichas ficam somente no navegador e podem ser exportadas. Não existe envio ao professor. Os comentários são acessíveis; use cenários novos na avaliação formal.

Edição: content.js (conteúdo), app.js (interações), style.css (aparência) e index.html (estrutura).

Hospedagem: GitHub Pages, branch main, pasta raiz. Atualizações nessa branch atualizam o site.

Material educacional, sem finalidade de prescrição. Condutas assistenciais dependem de prescrição validada e protocolos vigentes. Referências constam na Biblioteca. Os PDFs completos não fazem parte do repositório. Foto e currículo incluídos com autorização do professor. A figura científica mantém atribuição e direitos de terceiros; não foi concedida licença aberta a esses materiais.
